# CipherSolver
Vibecodovaná webová aplikace (https://prokocku.github.io/CipherSolver/) pro řešení běžných šifer jako morse, semafor, Braille, binárka, trojkovka, polský kříž, svátky a šifrovací mřížka.
Na iOS je možné ji v Safari, pomocí nabídky sdílet, uložit na plochu a tím z ní udělat plnohodnotnou aplikaci s ikonou, která bude fungovat offline, viz https://support.apple.com/cs-cz/guide/iphone/iphea86e5236/26/ios/26.
Inspirace šifrovací pomůcky Absolutno https://github.com/vasekp/sifry
