# CipherSolver
Vibecodovaná webová aplikace (https://prokocku.github.io/CipherSolver/) pro řešení běžných šifer jako morse, semafor, Braille, binárka, trojkovka a polský kříž.
Na iOS je možné ji v Safari, pomocí nabídky sdílet, uložit na plochu a tím z ní udělat plnohodnotnou aplikaci s ikonou, která bude fungovat offline.
Inspirace šifrovací pomůcky Absolutno https://github.com/vasekp/sifry
